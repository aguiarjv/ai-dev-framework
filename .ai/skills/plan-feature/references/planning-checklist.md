# Planning Checklist

Use this checklist for larger plans:

- Goal and success criteria are explicit.
- Current behavior and relevant code paths are identified.
- Public interfaces, types, commands, routes, events, or schemas are named.
- Data flow is described from input to output.
- Compatibility, migrations, and rollout concerns are covered.
- Error handling and fallback behavior are specified.
- Test cases cover success, failure, regression, and boundary scenarios.
- Assumptions are explicit and safe defaults are chosen.
