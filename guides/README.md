# Guides

This directory contains reusable guidance files that the framework can install
into target projects.

Guides should describe broadly useful development practices, conventions, and
workflows.

## Available Guides

- [Orchestration Workflow](orchestration-workflow.md) defines the primary
  agent's delegation, context, handoff, review, and completion workflow.
- [Multi-Project Workspace Structure](multi-project-workspace.md) defines the
  standard folder layout for a multi-project meta repository.
- [Plan and Task Management](plan-and-task-management.md) defines how managed
  projects organize plans, tasks, progress, handoffs, and completed plans.
- [Handoff Management](handoff-management.md) defines durable context transfer
  between agents.
- [Worktree Management](worktree-management.md) defines isolated task checkout
  planning, creation, assignment, and cleanup boundaries.
- [Review Management](review-management.md) defines how managed projects scope,
  perform, record, and update evidence-backed reviews.
- [Report Management](report-management.md) defines how managed projects create
  and maintain evidence-backed reports.
- [Architecture Decision Records](adr-management.md) defines when and how to
  record accepted decisions under project documentation.
- [Database Exploration](database-exploration.md) defines safe read-only live
  database investigation.
